# Basic HTML Website
project url: https://roadmap.sh/projects/basic-html-website

A simple multi-section personal portfolio website built using HTML5. This project focuses on creating a well-structured webpage with semantic HTML elements, internal navigation, and a contact form, without using CSS styling or JavaScript.

## 📌 Project Overview

The website represents a personal portfolio for a frontend developer. It includes sections for projects, work experience, education, teacher reviews, and contact information.

The main goal is to practice HTML fundamentals and learn how to organize website content using a clean and understandable structure.

## ✨ Features

* **Header and Navigation:** Navigation links to different sections of the website.
* **Projects Section:** Showcases sample projects such as an HTML portfolio, calculator, and quiz app.
* **Work Experience:** Displays work experience and open-source contributions.
* **Education:** Includes academic achievements and relevant coursework.
* **Teacher Reviews:** Displays sample reviews and reviewer information.
* **Contact Form:** Includes input fields for name, email, and message.
* **SEO Meta Tags:** Includes a page title, meta description, and author metadata.
* **Semantic HTML:** Uses elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
* **Internal Navigation:** Uses anchor links to navigate between page sections.
* **Single-Page Layout:** Organizes all portfolio content on one webpage.

## 🛠️ Technologies Used

* **HTML5** — Website structure and content.
* **SEO Meta Tags** — Basic search engine metadata.
* **HTML Forms** — Contact form structure and user input fields.

## 🔍 SEO

The HTML document includes basic metadata to describe the webpage to search engines.

```html
<title>Basic Html Website</title>

<meta name="description"
      content="Explore Yourname's CV, including frontend development skills, education, and career experience.">

<meta name="author" content="Your name">
```

These tags provide a page title, description, and author information. The placeholder values should be updated with the actual website owner's details.
